# Coração de Herói — Painel Público

Versão pública (sem nomes, RG ou qualquer dado pessoal) do painel de fatores de
risco cardiovascular do programa **Coração de Herói** — 1ª Policlínica do
Corpo de Bombeiros Militar do Estado do Rio de Janeiro (CBMERJ).

Contém apenas análises agregadas: prevalência de fatores de risco, testes
estatísticos, correlações e modelos — nenhuma linha nomina um militar.

Os módulos de Priorização clínica e Risco PREVENT nominal, que identificam
militares, **não existem** nesta versão — ficam restritos ao repositório
privado do programa.

Gerado automaticamente a partir de `coracao-de-heroi-dashboard` via
`make publico`. Não editar `index.html` diretamente aqui — ele é sobrescrito
a cada publicação.
